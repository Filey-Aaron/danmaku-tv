# 使用教程：给 Android TV 播放器加弹幕

VidHub 电视版是精确适配的；其它播放器（Kodi / Plex / Emby / MX / 当贝 / 系统播放器…）走通用识别。

> 不想碰命令行？看[新手说明书](for-beginners.md)，全程只用遥控器 + U 盘。
> 这份教程面向会用电脑（adb / Docker）的人。

这份教程假设你只想**把它装上、能用**。不需要懂 Android 开发，也不需要 Root。

全程大概 5 分钟；自己搭弹幕服务器再加 10 分钟。

---

## 0. 你需要什么

| 项目 | 说明 |
|---|---|
| 一台 Android TV / 电视盒子 | Android 8.0 及以上（实测机型：小米电视，Android 9） |
| VidHub 电视版（推荐） | 包名 `com.oumi.utility.media.hub`，精确适配，最稳 |
| 其它播放器 | Kodi / Plex / Emby / MX / 当贝 / 电视自带播放器，走通用识别，能用但精度差一些 |
| 局域网内的电视和电脑 | 电脑用 adb 装应用、传配置；没有电脑可以用 U 盘 + 遥控器 |
| 一个弹幕接口 | 推荐自建（免费、无限流），也可先用内置测试源试效果 |

> **它不改 VidHub 本身**。没有 Xposed、没有 hook、不碰播放器进程，只做两件事：
> 读取播放器界面上已经显示的文字（片名、进度），然后在自己的一层透明窗口上画弹幕。
> 所以 VidHub 升级一般不会让它失效，也不会因为注入被风控。

## 1. 安装

### 方式 A：用电脑（推荐，最快）

电脑装好 `adb`（Windows 可下载 platform-tools 解压后在该目录打开命令行）：

```bash
adb connect 192.168.1.50:5555      # 换成你电视的 IP
adb install -r danmu-tv-1.0.0.apk
```

电视 IP 在「设置 → 关于 → 状态信息」里能看到。

> 电视连不上？先在电视上打开「开发者选项 → USB 调试 / 网络调试」。
> 小米电视的开发者选项：设置 → 关于 → 产品型号，连按 5 次。

### 方式 B：只用电视（没有电脑）

1. 把 `danmu-tv-1.0.0.apk` 拷到 U 盘，插到电视上；
2. 用电视自带的文件管理器打开 APK，按提示允许「安装未知来源应用」；
3. 装完桌面上**不会出现图标**，这是故意的（见第 3 节怎么打开设置）。

## 2. 给两个权限

弹幕要画在别的应用上面，还要读播放器界面的文字，所以需要两个权限。

### 2.1 悬浮窗权限

**用电脑：**

```bash
adb shell appops set tv.yaohui.danmu SYSTEM_ALERT_WINDOW allow
```

**用遥控器：** 设置 → 应用 → 弹幕伴侣 → 特殊权限 → 显示在其他应用上层 → 允许。
（不同品牌路径略有差别，关键词是「悬浮窗」「显示在其他应用上层」「在其他应用上层显示」。）

### 2.2 无障碍服务（关键，容易踩坑）

**用遥控器：** 设置 → 无障碍 → 已下载的服务 → 弹幕伴侣 → 打开。

**用电脑：**

```bash
# ⚠️ 一定要把「已启用的服务」原样带上，用冒号拼在你的服务前面，否则会把别的服务顶掉
adb shell settings get secure enabled_accessibility_services
# 假设输出是 app.orchard.tv/app.orchard.tv.guard.HomeGuardService，那就：
adb shell settings put secure enabled_accessibility_services \
  'app.orchard.tv/app.orchard.tv.guard.HomeGuardService:tv.yaohui.danmu/tv.yaohui.danmu.DanmuA11yService'
adb shell settings put secure accessibility_enabled 1
```

> **为什么要注意：** 这个设置是「整串覆盖」的。直接 `put` 只写自己，会把电视厂商的
> 无障碍服务（比如某电视的桌面守护）关掉，可能出现别的问题。看到 `null` 才可以只写自己。

### 2.3 （可选，强烈推荐）让它开机自动恢复绑定

不少电视会在开机或清理内存时把第三方无障碍服务从列表里摘掉，表现是**重启后弹幕和菜单键手势都失效**。
如果你有 Root（Magisk），放一个开机脚本一劳永逸：

```bash
adb push tools/95-danmu-a11y.sh /data/local/tmp/95.sh
adb shell su -c 'cp /data/local/tmp/95.sh /data/adb/service.d/95-danmu-a11y.sh && chmod 755 /data/adb/service.d/95-danmu-a11y.sh'
```

脚本常驻盯着（每 20 秒一次）：列表里没有本服务就追加回去；列表里有但进程已经没了，会连续确认三次后强制重建一次绑定。
日志：`/data/local/tmp/danmu-a11y.log`。

没有 Root 也没关系，失效时手动重新打开一次无障碍开关即可。

## 3. 打开设置页

应用没有桌面图标（避免被电视桌面当成普通应用显示、也避免误触），用下面任一方式打开：

**① 遥控器手势（需服务已运行）**

在 VidHub **播放页面**里，快速连按两下「菜单键」（900ms 内，按三下也算）。设置页会盖在播放页上，按返回键退出。

> 这个手势的代价：为了拿到按键，服务要请求「过滤所有按键」，遥控器长按（比如音量连加）会变成一下一下按。
> 嫌烦就在设置里把「菜单键手势」关掉，改用下面的方式。

**② 电脑命令行**

```bash
adb shell am start -n tv.yaohui.danmu/.SettingsActivity
```

Windows 用户也可以直接双击仓库里的 `Open-Danmu-Settings.bat`（里面改一下电视 IP）。

> 设置页一出来，正在滚的弹幕会自动收起；关掉设置页回到播放器，弹幕自己接着滚。

## 4. 配置弹幕源

进设置页 → 「弹幕源」区。

### 4.1 先试内置测试源

「切换数据源」到 **内置测试源**，进任意一集播放，画面上会出现随机生成的测试弹幕。
这一步只验证「渲染和同步是通的」，弹幕内容是假的。

### 4.2 换成真的弹幕（推荐自建 danmu_api）

本项目对接 [danmu_api](https://github.com/huangxd-/danmu_api)（兼容弹弹play v2 接口）。

**在任意一台常开的机器上跑起来**（NAS、软路由、旧笔记本都行，只要有 Docker）：

```bash
docker run -d --restart unless-stopped \
  --name danmu-api -p 9321:9321 \
  -v /你的路径/danmu-api/config:/app/config \
  -e TOKEN=87654321 \
  --log-opt max-size=10m --log-opt max-file=3 \
  logvar/danmu-api:latest
```

**必须改一个配置**，否则切集快一点就报 429（默认限流 3 次/分钟）：
在挂载出来的 `config/.env` 里把

```
RATE_LIMIT_MAX_REQUESTS=3
```

改成

```
RATE_LIMIT_MAX_REQUESTS=0
```

然后 `docker restart danmu-api`。

**在设置页填写：**

| 字段 | 填什么 |
|---|---|
| 接口地址 | `http://192.168.1.100:9321`（换成跑 Docker 那台机器的 IP，末尾不要加斜杠） |
| TOKEN | 上面 `-e TOKEN=` 的值；没设就留空 |
| 切换数据源 | 切到「弹幕API」 |
| 保存并重载 | 点一下，正在播的这集会立刻重新拉取 |

点「测试连接」可以先用最近播过的片名试拉一次，能在几秒内返回条数就说明通了。

> 电脑上验证服务器是否正常：
> `curl "http://192.168.1.100:9321/api/v2/search/episodes?anime=片名"`

## 5. 调显示效果

设置页「显示」区，用左右方向键加减：

| 项 | 建议 |
|---|---|
| **弹幕开关** | 设置页最上面那一行，按钮写的是「按下去会做什么」（隐藏弹幕 / 显示弹幕），右边才是当前状态：绿色「● 显示中」/ 灰色「○ 已隐藏」。这只是隐藏画面上的弹幕，服务、按键手势、数据源都继续跑，点回来立刻恢复 |
|---|---|
| 字号 | 1080p 电视 24~40 之间比较舒服；调大后行距会一起变，看着更宽松 |
| 速度 | 190~280 像素/秒；太快来不及看，太慢会堵 |
| 不透明度 | 80~100；嫌挡脸可以降到 70 左右 |
| 显示区域 | **上部 40%**（默认）。老电视性能有限，区域越小合成越轻、越不容易卡 |
| 自动同步 | 保持开启。读不到进度时会用 Root 自动按一下「上」键召唤控制栏（不会暂停），2~3 秒内完成对齐 |
| 菜单键手势 | 见第 3 节，嫌遥控器长按变卡就关掉 |

改完不用重启，正在播的弹幕会立刻按新参数画。

## 6. 它到底怎么对齐时间

播放器界面只在控制栏出现时才显示进度（`02:07` 这种，精确到秒）。所以：

1. 控制栏出现 → 读一次真实进度，作为锚点；
2. 控制栏收起 → 用 `锚点 + 经过时间 × 倍速` 推算当前位置，弹幕按这个时间滚动；
3. 推算值跑出合理区间（拖动、跳转）→ 连续两轮确认后重新锚点；
4. 倍速用 6 秒以上的长窗口估计，不会因为秒级误差让弹幕速度忽快忽慢；
5. 暂停时冻结（靠系统音频状态判断），继续播放从原位接着走。

**这就是为什么有时右下角会提示「弹幕待同步 · 按一下遥控器」**：太久没读到进度，它不敢瞎猜。
按一下方向键让控制栏出来，1~2 秒就恢复（有 Root 且开了「自动同步」时它会自己按）。

## 7. 常见问题

**Q：装完，进播放页一直没有弹幕**

按顺序排查：

1. 是不是在**播放页**？列表页、详情页不会显示（详情页里的小窗预览也不算）。
2. 设置页「无障碍」显示「已开启」吗？没开就重新打开一次。
3. 数据源是不是还停在「内置测试源」而你以为连了服务器？
4. 点「测试连接」看能不能返回条数；返回 0 说明这个片名在数据源里没有收录（冷门剧、剧场版常见）。
5. 看日志：`adb logcat -s DanmuSvc`，正常会打印加载条数和位置推进。

**Q：显示「弹幕待同步 · 按一下遥控器」**

控制栏收起太久、或刚进播放页还没读到进度。按一下方向键让控制栏出现即可。
如果频繁出现，检查「自动同步」是否开着、设备有没有 Root。

**Q：重启电视后弹幕和菜单键都没了**

无障碍绑定被系统摘掉了。按 2.3 节放一个开机脚本，或手动重新打开无障碍开关。
底层原因：部分电视的守护应用会在开机时把「已启用的无障碍服务」重写一遍。

**Q：遥控器音量键长按不连发了**

「菜单键手势」开着的时候，所有按键都要过一次无障碍服务，长按会变成单步。设置里关掉即可恢复。

**Q：弹幕一多就卡**

先确认「显示区域」是上部 40%；再考虑把字号调大一档（视觉上更整齐，同样的微小抖动不明显）。
这台小米电视是 2014 年的 MStar 芯片，同时合成「1080p 视频 + 透明层」本身就有每秒 2~3 帧的上限，
弹幕层即使什么都不画也还有这么多丢帧——属于硬件天花板。

**Q：弹幕和画面不同步 / 串到别的剧**

先退到详情页再进一次。如果频繁串台，说明片名解析选错了条目，
把 `adb logcat -s DanmuSvc` 里 `loaded ...` 那行发出来，看得出它选了哪一集。

**Q：桌面找不到图标，怎么卸载**

设置 → 应用 → 弹幕伴侣 → 卸载。或者：

```bash
adb uninstall tv.yaohui.danmu
```

**Q：能不能用在别的播放器上**

可以，1.1 起内置了「所有播放器」模式（默认开）。VidHub 是精确适配（读固定控件 id），
其它播放器走通用识别：扫无障碍节点树，从界面文字里猜片名和进度，只要播放器是「全屏 + 有声音」
或者能读到时长 ≥ 1 分钟的进度条，就会挂上弹幕。

不工作的常见原因和自查方法：
1. 在播放页按遥控器唤出控制栏，进设置页看「识别记录」——它显示刚才读到的包名/片名/进度；
2. 片名是图片、或写的是文件路径，就搜不到弹幕；
3. 想彻底排掉某个 App：设置页「排除应用」填它的包名。

## 8. 还原 / 彻底清理

```bash
# 1. 关掉无障碍绑定（记得保留别的服务）
adb shell settings get secure enabled_accessibility_services
adb shell settings put secure enabled_accessibility_services '剩下的那串'

# 2. 删开机脚本
adb shell su -c 'rm -f /data/adb/service.d/95-danmu-a11y.sh'

# 3. 卸载
adb uninstall tv.yaohui.danmu
```

## 9. 隐私与合规

- 应用只读取**播放画面上已经显示的文字**（片名、两个时间），不读其他应用、不读屏幕内容、不上传任何数据。
- 唯一的外发请求是「用片名去你自己的弹幕接口查弹幕」，请求只发往你在设置里填的地址。
- 弹幕内容来自第三方接口，版权归原作者，仅供个人观看使用，请勿用于二次分发或商业用途。
