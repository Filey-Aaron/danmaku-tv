# 弹幕伴侣 · 新手说明书

> 这份是给「不想碰命令行」的人看的。全程只用遥控器 + 一个 U 盘。
> 想自己搭弹幕服务器、会用电脑敲命令的，看[进阶说明书](tutorial.md)。

![效果](screenshot-main.jpg)

---

## 一、这是啥

你看片子的时候，画面上多一层像 B 站那样的弹幕。

它不改你的播放器，也不用刷机。装好之后，播放视频的时候会自动出现弹幕，退出就没了。

**默认所有播放器都能用**：VidHub 是对着它专门做的，最准；其它播放器（Kodi、Plex、当贝播放器、电视自带播放器……）
靠"看画面上的字"来猜片名和进度，大多数情况能用，个别播放器可能认不准。

---

## 二、装之前确认三件事

1. **电视是安卓系统**（小米、Redmi、创维、海信、TCL、索尼这些智能电视基本都是）；
2. **电视里有个能放片的播放器**（VidHub 适配最准，其它播放器也能用）；
3. **有一个 U 盘**，或者家里有台电脑能和电视连同一个 WiFi。

三条都满足就能装。**不需要 root，不需要刷机。**

---

## 三、第一步：把安装包装到电视上

### 办法一：U 盘（最省事，不用电脑知识）

1. 把 `danmu-tv-1.0.0.apk` 这个文件拷到 U 盘里（放根目录，好找）；
2. U 盘插到电视的 USB 口；
3. 电视上打开「文件管理」或「媒体中心」，找到 U 盘；
4. 点这个 apk 文件；
5. 电视会问「是否安装」，选**安装**；
6. 如果弹出「禁止安装未知来源应用」，就按提示允许一下（一般在弹窗里点「设置」→ 允许，再回来点一次安装）。

> 装完发现**桌面上没有新图标** —— 这是正常的，故意的。怎么打开设置看第六节。

### 办法二：电视自带的「远程推送」

小米电视有「小米电视助手」，当贝市场能装「当贝助手」，都能从手机/电脑把 apk 推进电视。操作跟着界面提示点就行。

### 办法三：会用电脑的话

看[进阶说明书](tutorial.md)第 1 节，两条命令搞定。

## 四、第二步：给它开两个开关

这两个开关不开，弹幕出不来。都在电视的「设置」里，用遥控器操作。

### 开关①：允许它显示在其他应用上面

在电视设置里找这几个字眼之一：

- 「应用」→ 找到**弹幕伴侣** → 权限 → **显示悬浮窗 / 显示在其他应用上层** → 允许
- 或者：「设置」→「特殊应用权限」→「显示在其他应用上层」→ 找到**弹幕伴侣** → 允许

（小米电视路径：设置 → 应用 → 应用管理 → 弹幕伴侣 → 权限管理 → 显示悬浮窗）

### 开关②：打开无障碍（最关键的一步）

1. 打开电视设置；
2. 找到**「无障碍」**（有的电视叫「辅助功能」）；
3. 找到**「已下载的服务」**或**「已安装的服务」**（⚠️ 不是「视觉」「听觉」那些）；
4. 里面应该有**弹幕伴侣**，点它，打开开关；
5. 系统会弹一个提示框，说明这个应用能读取屏幕内容，点**确定 / 允许**。

> 看不到「弹幕伴侣」怎么办？说明安装没成功，回第三节重装一次。
> 打开后再回到这个列表，应该显示「已开启」。

## 五、第三步：让它有弹幕可放

**这一步是唯一有点麻烦的**，因为弹幕不是软件自带的，得有地方去查。

软件自带一个「测试弹幕」，内容都是假的，只用来确认「能显示」。

### 情况 A：家里已经有人搭好了弹幕服务

比如你的路由器、NAS 上装过，或者朋友给了你一个地址（长得像 `http://192.168.1.100:9321`）。

**填进去的方法：**

1. 先进 VidHub，随便放一集（要有画面在动）；
2. 在播放页里，**快速连按两下遥控器的「菜单键」**（按三下也行），会弹出设置页；
3. 找到「弹幕源」这块：
   - 「接口地址」这一行，把地址填进去，比如 `http://192.168.1.100:9321`（末尾不要加斜杠）；
   - 「TOKEN」：别人给你地址时一般也会给你一个口令，有就填，没有就留空；
   - 点「切换数据源」，让它变成**弹幕API**；
   - 点「保存并重载」；
4. 点一下「测试连接」，几秒后如果显示拉到了多少条，说明通了。

### 情况 B：只有电视，没有别人搭好的服务

那就先用**内置测试源**看看效果：

设置页 →「切换数据源」点到**内置测试源** → 回 VidHub 放一集。

屏幕上会出现一堆随机生成的假弹幕（内容没意义），但这说明**整个软件是通的**，只是没接真弹幕。

想要真弹幕，得有人帮你搭一个服务。搭这个需要一台常年开着的设备（路由器 / NAS / 旧电脑），具体在[进阶说明书](tutorial.md)第 4 节，可以把这个页面发给会弄的朋友。

### 情况 C：某部片子一条弹幕都没有

不一定是坏了。冷门片、刚上映的、剧场版，弹幕库里本来就可能没有。换一集热门剧试试就知道。

## 六、第四步：打开设置页的三种方式

装完没有桌面图标，用这三种方式进去：

1. **遥控器手势（最方便）**：在 VidHub **播放页**里，快速连按两下「菜单键」；
2. **系统设置**：设置 → 应用 → 弹幕伴侣 → 打开（有的电视没有这个入口）；
3. **电脑**：会用电脑的话，`adb shell am start -n tv.yaohui.danmu/.SettingsActivity`。

> 设置页是盖在画面上的一块面板，按**返回键**就退出，弹幕会自动恢复。

## 七、想调好看点（只用遥控器左右键）

设置页「弹幕显示」里，每一项都是按**左/右方向键**加减：

| 项目 | 怎么调 |
|---|---|
| **字号** | 嫌小就往右加。字调大后行距也会一起变大，看着更宽松 |
| **速度** | 太快来不及看就往左减，太慢会堵住画面就往右加 |
| **不透明度** | 嫌挡脸往左减到 70 左右；100 是最清楚 |
| **显示区域** | 在「全屏」和「上部 40%」之间切。**老电视建议用上部 40%**，更流畅 |
| **菜单键手势** | 见下面「一个小代价」 |

改完不用重启，正在播的弹幕立刻按新设置显示。

## 八、遥控器上的两个小动作

**① 连按两下菜单键 = 打开设置**
只在这个软件里有效，别的应用里按没反应。

**② 屏幕右下角出现「按一下遥控器」= 按一下方向键就行**
有时候它读不到播放进度，会提示你。按一下方向键，让播放器的控制栏冒出来，2~3 秒就恢复正常。
（如果电视 root 过，它自己会按，你不用管。）

---

## 九、一个小代价（可以关掉）

「菜单键手势」开着的时候，软件要接管遥控器的按键，**音量键长按不能连续加减了，得一下一下按**。

这是那个按键拦截带来的。嫌烦：

设置页 →「菜单键手势」→ 关掉 → 音量键恢复正常。

关掉以后怎么进设置？用第六节的方式 2 或 3（电脑命令 / 系统设置里的应用入口）。

## 十、出问题了对照这张表

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 进播放页一直没弹幕 | 90% 是无障碍没开 | 回第四节，重新打开「无障碍 → 已下载的服务 → 弹幕伴侣」 |
| 有弹幕但全是莫名其妙的话 | 还在用内置测试源 | 回第五节填真地址 |
| 右下角提示「按一下遥控器」 | 暂时读不到进度 | 按一下方向键，别按确认键（会暂停） |
| 播放页正常，退出去弹幕还在 | 极少见，服务卡住了 | 电视设置里把无障碍开关关掉再打开一次 |
| 重启电视后弹幕没了 | 电视开机会清理第三方无障碍服务 | 重新打开一次无障碍开关（有 root 的话可以用进阶说明书里那个脚本，一劳永逸） |
| 弹幕一多就卡 | 电视芯片吃不消 | 显示区域改成「上部 40%」，字号调大一点更好看 |
| 遥控器音量键不能长按了 | 菜单键手势开着 | 设置里关掉它 |
| 想彻底关掉弹幕 | — | 设置页里把「弹幕显示」关掉，或直接卸载 |

## 十一、不想要了怎么删

1. 电视设置 → 应用 → 找到**弹幕伴侣** → 卸载；
2. 顺手把「无障碍 → 已下载的服务 → 弹幕伴侣」关掉（卸载会自动关，但确认一下更保险）。

删完对电视没有任何影响，不留后台进程。

---

## 十二、它会不会偷看我的东西

- 它**只读播放画面上已经显示的字**：片名、已播时间、总时长。用来对齐弹幕时间。
- 它**不读别的应用**，不录屏、不上传任何数据。桌面、设置、聊天软件这类界面它一律跳过。
- 它唯一往外发的东西是：「拿片名去问你填的那个地址，这一集有没有弹幕」。地址是你自己填的，不填就不发。
- 弹幕内容来自第三方，版权归原作者，自己看就行，别拿去卖。
